# Fontes das imagens

As imagens desta pasta são geradas por `scripts/gerar_imagens.py` (identidade "Monochrome Net").

- O título "ROBOT" usa as letras da **Inter Display Bold** (Rasmus Andersson), convertidas em
  contorno no SVG. Licença SIL Open Font License 1.1 (<https://openfontlicense.org>).
- Os ícones das tecnologias vêm do Simple Icons (CC0, <https://simpleicons.org>). As marcas
  pertencem aos respectivos donos e aparecem só para indicar o que o projeto usa.
- O robô-orbe, os divisores e os ícones de seção foram desenhados para este projeto.
